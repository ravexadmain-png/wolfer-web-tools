Pull the structure out of any web page.

Wolfer Web Tools fetches a page, finds every stylesheet and script it depends on, and saves the lot into a tidy local folder. Written in Python. Runs in Termux.

What it does

One URL in, a working local copy of the page's front-end out.

Finds every stylesheet and script

The page is parsed with BeautifulSoup. Each external CSS and JavaScript file is located, resolved to a full address, and downloaded, even when the page uses relative or protocol-free links.

output/example.com/ index.html index.original.html assets/ css/ js/

Ready to open offline

The saved index.html points at the local copies. The untouched original is kept beside it.

Safe by default

Timeouts, retries, and a file size cap. A failed download never stops the run.

Made for Termux

Pure Python with two dependencies, requests and beautifulsoup4. Nothing to compile, no root needed, and the menu fits a phone screen.

Install in Termux

Five commands from a fresh Termux session.

  1. pkg update && pkg install python git -y
  2. git clone https://github.com/ravexadmain-png/wolfer-web-tools
  3. cd wolfer-web-tools
  4. pip install -r requirements.txt
  5. python main.py
